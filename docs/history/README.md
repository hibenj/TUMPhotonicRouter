# Historical documents

The files in this directory describe earlier states of the repository and
are kept as the record of how it got here, not as a description of the
current code: [`repository_finished_state.md`](repository_finished_state.md)
(the finished-state target for crossings and PLM, written 2026-07),
[`photonic_baseline.md`](photonic_baseline.md) and
[`profiling.md`](profiling.md) (2026-06 timing baselines on the since-deleted
toy benchmarks, and the profiling workflow of that time),
[`crossing_baselines.md`](crossing_baselines.md) and
[`crossing_flow_repair_ideas.md`](crossing_flow_repair_ideas.md) (the
crossing modes and repair ideas of 2026-07, among them the `window` and
`collision` modes removed in 2026-09), and
[`tumphotonicrouter_vs_lidar.md`](tumphotonicrouter_vs_lidar.md) and
[`tumphotonicrouter_vs_lidar2_functionality.md`](tumphotonicrouter_vs_lidar2_functionality.md)
(comparisons with LiDAR, written 2026-06 and 2026-07). Module names,
flags, modes and numbers in them may no longer exist or hold; the current
system is [`../ARCHITECTURE.md`](../ARCHITECTURE.md), and what changed since
is [`../../CHANGELOG.md`](../../CHANGELOG.md). `../astar_quality_baseline.json`
stays in `docs/` because `scripts/profile_astar.py` reads it by default.
